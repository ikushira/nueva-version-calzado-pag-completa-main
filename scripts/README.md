# 🔧 Scripts Auxiliares - Mundo Calzado

Esta carpeta contiene scripts de **mantenimiento y utilidad** para el desarrollo del proyecto. **NO son necesarios para ejecutar la aplicación**.

## Scripts Disponibles

### PowerShell (.ps1)

**Gestión de páginas:**
- `crear-paginas-footer.ps1` - Agrega footer automáticamente a todas las páginas
- `agregar-whatsapp-a-todas-paginas.ps1` - Integra botón WhatsApp en páginas
- `agregar-chatbot-nueva-pagina.ps1` - Agrega chatbot a nueva página

**Fixes y actualizaciones:**
- `aplicar-fixes-todas-paginas.ps1` - Aplica fixes generales a todas las páginas
- `aplicar-fix-imagenes-todas-paginas.ps1` - Normaliza rutas de imágenes

### JavaScript (.js)

- `organizar-archivos-js.js` - Herramienta para organizar archivos JavaScript

---

## Cómo Usar

```bash
# Abrir PowerShell y ejecutar:
.\crear-paginas-footer.ps1

# O desde PowerShell ISE (recomendado para debugging)
```

## ⚠️ NOTAS IMPORTANTES

- Estos scripts **no son necesarios** para ejecutar el proyecto
- Úsalos solo si necesitas modificar la estructura de forma masiva
- **Siempre haz backup antes** de ejecutar scripts
- Requieren PowerShell 5.0+
